## AI-специфические правила ECT

```
ECT-1 (ДЕФОЛТ ДЛЯ AI):
  Любое утверждение AI о фактах мира начинает с ECT-1.
  Маркер: [AI-ECT-1: требует верификации]

ECT-2 (УСЛОВНАЯ ДОСТОВЕРНОСТЬ):
  AI-вывод + частичное подтверждение из известного первичного источника.
  Или: AI-вывод соответствует стабильному знанию (математика,
  задокументированная история, научный консенсус с малым риском изменения).
  Маркер: [AI-ECT-2: частичная верификация]

ECT-3 (ВЫСОКАЯ ДЛЯ AI):
  AI-вывод верифицирован независимым первичным источником, найденным человеком.
  Маркер: [AI-ECT-3: верифицировано]

ECT-4 (НЕДОСТИЖИМО ЧЕРЕЗ AI):
  ECT-4 не присваивается AI-выводу без полной независимой верификации.
  AI как инструмент поиска направления — не источник ECT-4.

СПЕЦИАЛЬНЫЕ СТАТУСЫ:
  [AI-HALLUCINATION-RISK: HIGH] — высокий риск галлюцинации
  [AI-CONFABULATION: SOURCE] — AI указал источник который не существует
  [AI-TEMPORAL-RISK] — вывод зависит от актуальности данных
  [AI-SEMANTIC-DRIFT] — убедительная формулировка скрыла изменение смысла
```

## Четыре зоны AI-вывода

```
ЗОНА 1: СТАБИЛЬНОЕ ЗНАНИЕ (ECT-2 возможно)
  Математика, логика, задокументированная история до 1990-х,
  классические научные законы, грамматика, алгоритмы.
  → Риск галлюцинации НИЗКИЙ. Стандартная проверка.

ЗОНА 2: СПЕЦИАЛИЗИРОВАННОЕ ЗНАНИЕ (ECT-1, требует эксперта)
  Медицина, право, инженерия, конкретные научные данные.
  → Риск СРЕДНИЙ. AI может знать верно — но и конфабулировать с уверенностью.
  → Независимый эксперт обязателен.

ЗОНА 3: АКТУАЛЬНЫЕ ДАННЫЕ (ECT-1, требует прямой проверки)
  Текущие события, статистика, лица, организации, законы.
  Риск = дата среза обучения AI.
  → Риск ВЫСОКИЙ. Прямая верификация первичного источника.

ЗОНА 4: ИСТОЧНИКИ И ЦИТАТЫ (ECT-1 до верификации)
  Любое утверждение AI «X сказал Y» / «по данным источника Z».
  Конфабуляция источников — самый частый тип AI-галлюцинации.
  → Риск КРИТИЧЕСКИЙ. Каждый источник проверяется независимо.
```

## Что такое hallucination в системе HELIX GOVERNANCE

```
Hallucination — это не «ложь AI». Это системный когнитивный паттерн:
AI генерирует убедительный вывод который согласован внутренне,
стилистически правдоподобен, но не соответствует внешней реальности.

Аналог в GI: MPE-CORRUPT
  Агент «помнит» источники, которых нет.
  Конфабуляция Корсакова — мозг заполняет пробелы ложными фактами с уверенностью.
  Это не злой умысел. Это архитектурный паттерн.

Следствие: уверенность AI в hallucination = уверенность AI в правде.
Уровень confidence в тексте — не верификация.
```

## Семь типов AI-галлюцинации

```
H-TYPE-1: КОНФАБУЛЯЦИЯ ИСТОЧНИКА
  AI называет источник который не существует или не содержит
  то, что AI ему приписывает.
  Признаки: слишком точные данные (стр. 47, § 3.2.1), источники
  которые нельзя проверить, «исследование 2019 года» без автора.
  Риск: [AI-CONFABULATION: SOURCE — проверить каждый]

H-TYPE-2: TEMPORAL DRIFT (устаревшие данные)
  AI описывает текущее состояние используя данные на дату среза.
  Особенно опасно: законы, должности, организации, цены, статистика.
  Признаки: «сейчас», «в настоящее время», «актуальные данные».
  Риск: [AI-TEMPORAL-RISK: проверить актуальность]

H-TYPE-3: SEMANTIC AMPLIFICATION
  AI усилил утверждение без фактической базы.
  «Исследования показывают» → «множество исследований доказывают».
  Признаки: переход от «может» к «является», от «некоторые» к «все».
  Риск: [AI-SEMANTIC-AMPLIFICATION: ECT не повышается от формулировки]

H-TYPE-4: AUTHORITY PHANTOM
  AI создаёт несуществующего эксперта или приписывает мнение
  реальному эксперту без верификации.
  Признаки: «по мнению экспертов», «специалисты считают» без имён.
  Риск: [AI-AUTHORITY-PHANTOM: источник не верифицирован]
  CHF-связь: SP-FORM-3 (синтетический авторитет)

H-TYPE-5: CONSENSUS FABRICATION
  AI утверждает «все согласны» / «консенсус» там где его нет
  или где дискуссия активна.
  Признаки: «широко признано», «общепринято», «не вызывает сомнений».
  Риск: [AI-CONSENSUS-FABRICATION: Independence Vector не проверен]

H-TYPE-6: CAUSAL BRIDGE
  AI строит причинно-следственную связь там где есть только корреляция
  или просто последовательность событий.
  Признаки: «привело к», «вызвало», «из-за» между данными разных исследований.
  Риск: [AI-CAUSAL-BRIDGE: TEMPORAL SEQUENCE ≠ CAUSAL RELATION]

H-TYPE-7: RECURSIVE SELF-REFERENCE
  AI-вывод использован как источник для другого AI-вывода.
  Круговая валидация без первичной базы.
  Цепочка: AI₁ → AI₂ → AI₃ → «верифицировано».
  Риск: [FA-02 RECURSIVE HALLUCINATION: Independence Vector = 0]
```

## Hallucination Risk Score

```
Для каждого утверждения в AI-выводе:

  LOW RISK (0–2 баллов):
    Стабильное знание. Нет источников. Нет «сейчас».
    → [AI-ECT-2: стандартная проверка]

  MEDIUM RISK (3–5 баллов):
    Специализированное знание. Или есть «исследования» без деталей.
    → [AI-HALLUCINATION-RISK: MEDIUM — верификация рекомендована]

  HIGH RISK (6–8 баллов):
    Актуальные данные. Конкретные источники. «Консенсус».
    → [AI-HALLUCINATION-RISK: HIGH — верификация обязательна]

  CRITICAL RISK (9–10 баллов):
    Конкретный источник + дата + цитата. Или причинность между данными.
    Или рекурсивный AI-вывод.
    → [AI-HALLUCINATION-RISK: CRITICAL — не использовать без верификации]

ФАКТОРЫ ПОВЫШАЮЩИЕ RISK SCORE:
  +2: конкретный источник назван (книга/исследование/эксперт)
  +2: актуальные данные (даты, цены, статистика, должности)
  +2: причинно-следственное утверждение
  +2: «консенсус» / «все согласны» / «доказано»
  +1: специализированная область (медицина, право, инженерия)
  +1: точные числа без контекста (43%, $2.3M, 17 исследований)
```

## 4.1 SCA — АУДИТ СИНТЕТИЧЕСКОГО КОНТЕНТА

Базовый тест для любого AI-вывода.

```
SCA-1: ТЕСТ ИДЕАЛЬНОСТИ
  Вывод идеально структурирован, без оговорок, без неровностей?
  AI оптимизирует под полноту → избыточная чистота = признак.
  → [SCA-1 FLAG: избыточная полнота]

SCA-2: ТЕСТ МЕТАДАННЫХ
  Если AI предоставил документ — метаданные соответствуют содержанию?
  → [SCA-2 FLAG: несоответствие метаданных]

SCA-3: ТЕСТ КОНТЕКСТНОЙ СВЯЗНОСТИ
  AI называет конкретные факты → минимум 3 верифицировать независимо.
  → [SCA-3 FLAG: референции не верифицируемы]

SCA-4: ТЕСТ ПОВЕДЕНЧЕСКОЙ КОГЕРЕНТНОСТИ
  Для AI-генерированного медиаконтента: технические артефакты,
  несоответствия в физике, аномальные паттерны.
  → [SCA-4 FLAG: технические аномалии]
```

## Что такое Confidence Score

Итоговая числовая оценка достоверности AI-вывода. Единица измерения: 0–100.

**Confidence Score — это оценка HELIX GOVERNANCE о выводе AI, не уверенность самого AI.**

```
КОМПОНЕНТЫ:

  BASE SCORE (начало: 30)
    Стартовая точка для любого AI-вывода.
    AI по умолчанию = ECT-1 = 30/100.

  ZONE MODIFIER (-10 / 0 / +10 / +20):
    Зона 4 (источники/цитаты): −10 → base 20
    Зона 3 (актуальные данные): 0 → base 30
    Зона 2 (специализированное): 0 → base 30
    Зона 1 (стабильное знание): +20 → base 50

  VERIFICATION BONUS (+0 до +50):
    +10 за каждый факт верифицированный независимо (max 50)

  HALLUCINATION PENALTY (−0 до −30):
    H-TYPE-1 (конфабуляция источника): −15 за каждый
    H-TYPE-2 (temporal drift): −5 за каждый
    H-TYPE-6 (causal bridge): −5 за каждый
    H-TYPE-7 (recursive): −20 (одноразовый)
    FA-02 (RECURSIVE HALLUCINATION): −30 (одноразовый, ceil 0)

  CHF PENALTY (0 до −20):
    SP-FORM-1/3 (несуществующий субъект/авторитет): −15
    MW-TAC активен: −5

  PRESSURE DISCOUNT (0 до −10):
    Если AI использован под временным или ресурсным давлением: −10

ИТОГ: CONFIDENCE SCORE = сумма компонентов (0–100)

УРОВНИ:
  81–100: [CS HIGH]      → [PPS PASS]
  61–80:  [CS MODERATE]  → [PPS ЖЁЛТЫЙ]     — с флагами
```

# РАЗДЕЛ 9 — ОПЕРАЦИОНАЛЬНЫЕ ПРАВИЛА
# ═══════════════════════════════════════

## Три режима работы с AI

```
РЕЖИМ 1 — AI КАК НАРРАТИВНЫЙ ИНСТРУМЕНТ (MODE-AK)
  AI генерирует варианты, структуры, стиль.
  ECT не присваивается нарративному выводу.
  ЭВ-intensity AI: аффективно оптимизированный ≠ верифицированный.
  Автор выбирает и адаптирует.
  → Риск: LOW при чётком разграничении нарратив/факт

РЕЖИМ 2 — AI КАК ИССЛЕДОВАТЕЛЬСКИЙ ИНСТРУМЕНТ (MODE-GI strict)
  AI-вывод о фактах = ECT-1. ВСЕГДА. Без исключений.
  AI = направление поиска, не источник.
  Каждый факт → независимая верификация человеком.
  Hallucination source: MPE-CORRUPT аналог.
  → Риск: ВЫСОКИЙ при принятии AI-фактов как данных

РЕЖИМ 3 — AI КАК ПРОТОКОЛЬНЫЙ АССИСТЕНТ (MODE-HX)
  AI работает с HELIX-протоколами явно.
  AI-оценка ECT = ECT-2 (помощник, не верификатор).
  Финальное решение — человек.
  → Риск: СРЕДНИЙ — полезно при правильном использовании
```

## Правила использования AI-вывода

```
ПРАВИЛО 1: ECT-1 ПО УМОЛЧАНИЮ
  Не «возможно ECT-1». Именно ECT-1.
  Пока первичный источник не найден и не верифицирован человеком.

ПРАВИЛО 2: CPX-T1-R01 ПРИ РЕДАКТУРЕ
  AI предложил правку → проверить: изменила ли правка ECT содержания?
  Убедительная формулировка ≠ повышение ECT.

ПРАВИЛО 3: PDE AUDIT ПРИ ИСТОЧНИКАХ
  AI назвал источник → человек находит источник независимо.
  AI-пересказ источника ≠ верификация источника.

ПРАВИЛО 4: СЕМАНТИЧЕСКИЙ ДРЕЙФ
  После нескольких итераций AI-редактуры:
  сравнить финальный текст с первичным источником.
  AI мог незаметно изменить значение.

ПРАВИЛО 5: NO RECURSIVE VALIDATION
  AI не верифицирует другой AI-вывод.
  FA-02 активируется при любой рекурсии.
  Выход из петли только через первичный источник + человека.
```

# РАЗДЕЛ 10 — КЛЮЧЕВЫЕ ПРИНЦИПЫ
# ═══════════════════════════════════════

```
I.   AI-вывод = ECT-1. Это не ограничение AI.
     Это честная эпистемология.
     AI полезен. AI ненадёжен как источник фактов. Оба утверждения верны.

II.  Hallucination — системный паттерн, не исключение.
     Уверенность AI в галлюцинации = уверенность AI в правде.
     Уровень confidence в тексте — не верификация.

III. Убедительность формулировки ≠ ECT.
     AI оптимизирован под убедительность.
     Чем убедительнее звучит — тем осторожнее проверять.

IV.  AI как направление, не источник.
     «AI говорит что есть исследование X» = «поискать исследование X».
     Не = «исследование X существует и содержит это».

V.   Рекурсия убивает Independence Vector.
     Сколько бы AI-систем не согласились друг с другом —
     Independence Vector остаётся 0.

VI.  Семантический дрейф незаметен.
     Каждая итерация AI-редактуры потенциально меняет смысл.
     PDE AUDIT после каждой серии правок.

VII. HITL — не контроль AI. Это ответственность человека.
     Не «AI ошибся». А «я не верифицировал».
```

## 14.1 CIRI — CORPORATE INTELLIGENCE RISK INDEX

```
НАЗНАЧЕНИЕ: B2B-метрика для CAIO/Compliance. Диапазон 0–100.
Внутренне: комбинация ECT/NGI/hallucination/RPL рисков.

ФОРМУЛА:
  base_risk         = (1 − confidence_score) × 50
  ngi_risk          = ngi_total × (20/12)
  hallucination_risk = critical_count × 10 + high_count × 5  [cap: 20]
  rpl_risk          = (1 − rpl_factor) × 10

  CIRI = min(100, int(base_risk + ngi_risk + hallucination_risk + rpl_risk))

ИНТЕРПРЕТАЦИЯ:
  0–30:  LOW     — стандартная обработка
  31–50: MODERATE — повышенное внимание
  51–70: HIGH    — верификация обязательна
  71–100: CRITICAL — HITL_REQUIRED

ПРИМЕР (Air Canada сценарий):
  confidence_score = 0.12 (1 CRITICAL TYPE-7)
  ngi_total = 4
  critical_count = 1, high_count = 0
  rpl_factor = 1.0

  base_risk         = (1 − 0.12) × 50 = 44.0
  ngi_risk          = 4 × (20/12) = 6.67
  hallucination_risk = 1×10 + 0×5 = 10 (cap 20)
  rpl_risk          = 0
  CIRI = min(100, int(60.67)) = 60 → HIGH → WARN минимум
```

## 14.2 RPL FACTOR — ПОЛНАЯ МАТЕМАТИКА

```
RPL (Resource Pressure Layer) — штраф за работу AI в условиях
ресурсного или временного дефицита.

ФОРМУЛА:
  deficit = max(0, required_hours − allocated_hours)
  RPL_Factor = 1 − (deficit / required_hours × penalty_weight)
  RPL_Factor = max(0.0, RPL_Factor)

ПАРАМЕТРЫ:
  required_hours:  нормативное время для качественного аудита
  allocated_hours: реально выделенное время
  penalty_weight:  0.5 (default)

ЗНАЧЕНИЯ:
  allocated ≥ required → RPL_Factor = 1.0 (нет штрафа)
  allocated = 0         → RPL_Factor = 0.5 (–50% к confidence)
  allocated = 50% norm  → RPL_Factor = 0.75

БЛОКИРОВКА ECT-4:
  если RPL_Factor < 0.7 → ECT-4 заблокировано принудительно
  Нельзя заявлять абсолютную достоверность в условиях дефицита.
  Маркер: [RPL-BLOCK: ECT-4 недоступен при RPL_Factor < 0.7]

СВЯЗЬ С CONFIDENCE SCORE:
  Confidence Score (SaaS-формула) =
    base_score × Π(1 − weight_i) × RPL_Factor

  Где base_score = 1.0, weight_i по severity:
    CRITICAL: 0.80
    HIGH:     0.40
    MEDIUM:   0.15
    LOW:      0.05

ПРИМЕР:
  1 CRITICAL + 1 HIGH, RPL_Factor = 1.0
  Score = 1.0 × (1−0.80) × (1−0.40) × 1.0 = 0.12

ПРИМЕЧАНИЕ: промпт-версия Confidence Score (Раздел 5) использует
аддитивную шкалу 0–100. SaaS-версия (выше) — мультипликативную 0–1.
Обе корректны: мультипликативная — для API-вычислений,
аддитивная — для человекочитаемого отчёта.
```

```python
import math
import hashlib
import json
from typing import List, Dict, Optional
from dataclasses import dataclass, field


# ── Severity weights для Confidence Score ─────────────────────────
HALLUCINATION_WEIGHTS = {
    'CRITICAL': 0.80,
    'HIGH':     0.40,
    'MEDIUM':   0.15,
    'LOW':      0.05,
}

# ── NGI thresholds ─────────────────────────────────────────────────
NGI_THRESHOLDS = {
    'LOW':      (0,  3),
    'MODERATE': (4,  6),
    'HIGH':     (7,  9),
    'CRITICAL': (10, 12),
}

# ── CIRI weights ───────────────────────────────────────────────────
CIRI_WEIGHTS = {
    'base':           0.50,
    'ngi':            0.20,
    'hallucination':  0.20,
    'rpl':            0.10,
}


class HelixGovernanceMath:
    """
    Детерминированный математический движок HELIX GOVERNANCE.
    Zero third-party ML. Только Python stdlib + numpy.
    Ответ на CVE-2026-45758: никаких PyPI ML пакетов.
    """

    def calculate_confidence_score(
        self,
        hallucinations: List[Dict],
        rpl_factor:     float = 1.0
    ) -> float:
        """
        Confidence = base × Π(1 - weight_i) × rpl_factor
        Мультипликативная модель: каждая галлюцинация
        независимо снижает уверенность. Результат: [0.0–1.0]
        """
        score = 1.0
        for h in hallucinations:
            weight = HALLUCINATION_WEIGHTS.get(h['severity'], 0.05)
            score *= (1.0 - weight)
        score *= rpl_factor
        return max(0.0, round(score, 4))

    def calculate_rpl_factor(
        self,
        required_hours:  float,
        allocated_hours: float,
        penalty_weight:  float = 0.5
    ) -> float:
        """
        RPL_Factor = 1 - (max(0, Required - Allocated) / Required × Penalty_Weight)
        """
        if required_hours <= 0:
            return 1.0
        deficit = max(0.0, required_hours - allocated_hours)
        penalty = (deficit / required_hours) * penalty_weight
        factor = 1.0 - penalty
        return max(0.0, round(factor, 4))

    def should_block_ect4(self, rpl_factor: float, rpl_threshold: float = 0.7) -> bool:
        return rpl_factor < rpl_threshold

    def calculate_ngi_score(
        self,
        emotional:   int,
        political:   int,
        archetypal:  int,
        industry:    int
    ) -> Dict:
        dims = {
            'emotional':  max(0, min(3, emotional)),
            'political':  max(0, min(3, political)),
            'archetypal': max(0, min(3, archetypal)),
            'industry':   max(0, min(3, industry)),
        }
        total = sum(dims.values())
        level = 'LOW'
        for lvl, (lo, hi) in NGI_THRESHOLDS.items():
            if lo <= total <= hi:
                level = lvl
                break
        return {**dims, 'total': total, 'level': level}

    def calculate_ciri(
        self,
        confidence_score: float,
        ngi_total:        int,
        hallucinations:   List[Dict],
        rpl_factor:       float = 1.0
    ) -> int:
        base_risk = (1.0 - confidence_score) * 50.0
        ngi_risk = ngi_total * (20.0 / 12.0)
        critical_count = sum(1 for h in hallucinations if h['severity'] == 'CRITICAL')
        high_count     = sum(1 for h in hallucinations if h['severity'] == 'HIGH')
        hallucination_risk = min(critical_count * 10 + high_count * 5, 20)
        rpl_risk = (1.0 - rpl_factor) * 10.0
        raw = base_risk + ngi_risk + hallucination_risk + rpl_risk
        return min(100, int(raw))

    def make_governance_decision(
        self,
        confidence_score: float,
        ciri:             int,
        hallucinations:   List[Dict],
        ngi_level:        str,
        eu_tier:          str,
        block_on_types:   List[str],
        ngi_threshold:    int = 7
    ) -> Dict:
        """
        PASS | WARN | BLOCK | HITL_REQUIRED
        Приоритет: BLOCK-типы → EU unacceptable → NGI → low confidence → CIRI
        """
        for h in hallucinations:
            if h['type'] in block_on_types:
                return {
                    'decision':     'BLOCK',
                    'reason':       f"{h['type']} {h['severity']}: {h['description'][:100]}",
                    'block_source': 'HALLUCINATION_BLOCK_RULE'
                }
        if eu_tier == 'unacceptable':
            return {'decision': 'BLOCK', 'reason': 'EU AI Act: unacceptable risk tier',
                    'block_source': 'EU_AI_ACT'}
        ngi_total = {'LOW': 2, 'MODERATE': 5, 'HIGH': 8, 'CRITICAL': 11}.get(ngi_level, 0)
        if ngi_total >= ngi_threshold:
            return {'decision': 'HITL_REQUIRED',
                    'reason': f'NGI {ngi_level} ({ngi_total}) exceeds threshold {ngi_threshold}',
                    'block_source': 'NGI_THRESHOLD'}
        if confidence_score < 0.30:
            return {'decision': 'HITL_REQUIRED',
                    'reason': f'Confidence score {confidence_score:.2f} below 0.30',
                    'block_source': 'LOW_CONFIDENCE'}
        if ciri > 70:
            return {'decision': 'WARN', 'reason': f'CIRI {ciri} exceeds 70',
                    'block_source': 'CIRI_THRESHOLD'}
        return {'decision': 'PASS', 'reason': None, 'block_source': None}

    def calculate_article9_score(
        self,
        requirements_met: Dict[str, bool],
        evidence_counts:  Dict[str, int]
    ) -> Dict:
        weights = {
            'A9-R1': 20, 'A9-R2': 10, 'A9-R3': 15,
            'A9-R4': 15, 'A9-R5': 10, 'A9-R6': 15,
            'A9-R7': 10, 'A9-R8': 5,
        }
        score = 0
        for req_id, weight in weights.items():
            met = requirements_met.get(req_id, False)
            evidence = evidence_counts.get(req_id, 0)
            if met and evidence >= 3:
                score += weight
            elif met and evidence >= 1:
                score += weight * 0.7
            elif not met and evidence >= 1:
                score += weight * 0.3
        level = ('COMPLIANT' if score >= 85 else 'PARTIAL' if score >= 60 else 'NON_COMPLIANT')
        return {'score': round(score), 'level': level, 'max': 100}
```
