The audit record — six reports

In August 2026 the engine was read line by line against the exact text of its governing specifications — not a summary, and not a prior comment claiming everything was fine. Fourteen discrepancies were found and fixed the same day, each with tests.

What is not proven here

There is no independent verification. Every piece of evidence originates in one repository belonging to one person. No outside party has confirmed anything. A reviewer should discount that, and is right to.

This is not a concession extracted under pressure — the verdict was reached by the product's own audit, run over the material of this very outreach campaign. Hence the order of asking: the first request is not for money, but for an outsider to run the tests and say what they see.

The system is live

This is a deployed site, not a specification: web-production-b540f.up.railway.app — three separate products on one deployment, live model calls, real grounded investigations. Sign-in via Google. A guided walkthrough is available on request.

The source code and the specifications themselves remain private. Read access is granted to any reviewer without conditions — hesitation there costs more than any risk. Every figure on this page is reproducible within an hour given that access.
