# Спека «живости» интерфейса (28.10.2026)

Контракт для задачи, которая идёт СЛЕДУЮЩЕЙ за тёмной тональной системой
(агент ВИЗУАЛ). Владелец 28.10.2026, дословно: «посмотри, как там плавают
значки, как на каждой иконке есть пояснения… топорный сайт, он не живой…
сравни с тем, что ты сделал». Документ существует, чтобы «живость» была
набором проверяемых механик, а не вкусовщиной.

| механика | betterstack.com | наш бандл/стили |

| правил `:hover` | 153 | 33 в `app.css` + 28 в `tokens.css`, почти все только цвет |

| дышащие индикаторы (`animate-pulse`, `animate-ping`) | есть | нет |

`grep -c "@keyframes" frontend/src/styles/*.css`, для референса —

## Механики, которые нужно добавить

1. **Подсказка на каждой иконке.** Компонент `Tooltip` (CSS-only, атрибут
   `data-tip`), появление через 150 мс, по наведению И по фокусу с клавиатуры.
   Навесить на ВСЕ органы управления без текста: иконки навигации, кнопки
   инструментов, микрофон, кнопку помощника, значки статусов. Пояснение обязано
   быть на языке интерфейса (ключ i18n), а не только в `aria-label`.
2. **Дышащие статус-точки.** `pulse` у состояний «слушаю», «пауза расходов»,
   «идёт проверка»; `ping` один раз в момент прихода нового результата.
3. **Одна медленная лента на титульной.** Бегущая строка 30 s с датированными
   достижениями из `docs/ПОМОЩНИК_БАЗА_ЗНАНИЙ.md` (числа и даты уже проверены
   сторожем `tests/test_база_знаний_против_протокола.py`). Лента замирает под
   курсором и на фокусе. Вторую ленту не добавлять: живость не означает карусель
   из всего подряд.
4. **Подъём при наведении.** Карточки и кнопки: `translateY(-2px)` + ступень
   тона/тень, 200 мс `cubic-bezier(.2,0,0,1)`; на нажатие −1 px обратно.
5. **Оживающие счётчики.** Числа титульной (уже живые через
   `/api/meta/counts` и датированные замерами) досчитываются за 600 мс при
   первом появлении в кадре; после досчёта показывают точное значение без
   округлений.
6. **Появление по прокрутке.** `IntersectionObserver`: opacity 0→1 и
   translate 8px→0, 225 мс; без каскадных задержек длиннее 120 мс.
7. **Плавающий помощник.** Кнопка с волной: штрихи волны анимируются во время
   слушания, ореол при наведении; панель открывается пружиной 220 мс (уже
   есть в `assistant.css`).
8. **Видимый фокус вместо `outline:none`.** Аудит 28.10 нашёл невидимый фокус
   у полей «Найти книгу» и «Название рукописи» и пять целей нажатия ниже
   24 px: кольцо фокуса возвращается везде, мелкие цели укрупняются до 24 px
   минимум (владелец работает голосом и с ограниченной моторикой).

## Предохранители

- `@media (prefers-reduced-motion: reduce)` отключает ВСЕ перечисленные
  движения; подсказки и фокус остаются.
- Анимируются только `transform` и `opacity`: никаких анимаций ширины, высоты
  и `top/left` (это пересчёт раскладки на каждом кадре).
- Бесконечных анимаций не больше трёх одновременно на экране.
- `frontend/src/styles/app.css` не правится: его замораживают
  `tests/test_canon_registry_and_one_design.py` и
  `tests/test_frontend_bundle_matches_source.py` (бумажные цвета обязаны
  доехать до бандла). Живость живёт в `tokens.css`/`motion.css` слоем поверх.
- Добавленный CSS не больше ~200 строк: живость, которая тяжелее полезного
  кода, — это не живость.

## Приёмка

- `grep -c "@keyframes" frontend/src/styles/*.css` суммарно ≥ 6; правил
  `:hover` с `transform` ≥ 20.
- Новый дымовой тест: у каждой кнопки без текстового содержимого есть
  `aria-label` И `data-tip`; у полей ввода фокус видим (computed
  `outline-style` не `none` при `:focus-visible`).
- Дымовые и bundle-тесты зелёные; `npm run build` без предупреждений о новых
  ошибках; манифест пересобирает ведущий последним шагом.
- Владелец смотрит локально `http://127.0.0.1:8010` и даёт заметки голосом;
  заметки правятся до коммита, а не после.
